# 投资机构法律尽调 Skills

本仓库包含两个相互独立、按项目阶段衔接的 Codex skill。两个文件夹可以分别安装或分别维护，也可以同时放入同一 skills 目录，由项目资料阶段自动路由。

## 阶段划分

| 项目阶段 | 使用 skill | 主要流程 | 最终交付 |
|---|---|---|---|
| BP、立项报告、路演材料阶段 | `early-investment-legal-dd` | 对话确认行业 → 对话展示尽调关注重点 → 客户确认 | 初步尽调清单 Word |
| 已收到首轮或后续尽调资料 | `full-investment-legal-dd` | 先生成尽调重点及问题分析 Word → 客户确认 | 补充尽调清单 Word |
| 资料达到门槛，或客户明确要求完整报告 | `full-investment-legal-dd` | 完整事实核验、法律分析和证据勾稽 | 正式完整版法律尽调报告 Word |

## 两个独立 skill

### `early-investment-legal-dd`

用于早期投资筛查。行业确认和尽调关注重点均在对话中完成；客户确认后才生成初步文件清单。收到成批资料后应切换到完整版 skill。

### `full-investment-legal-dd`

用于资料回传后的补充尽调和正式完整版报告。补充尽调设置客户确认节点，不会在问题分析完成后自动生成补充清单。资料达到出具门槛或客户明确要求时，可生成正式完整版报告。

## 安装

将需要的 skill 文件夹复制到 Codex skills 目录。例如：

```text
~/.codex/skills/early-investment-legal-dd/
~/.codex/skills/full-investment-legal-dd/
```

两个文件夹均包含独立的 `SKILL.md`、界面配置及所需参考文件，不依赖本仓库根目录运行。

## 隐私与使用边界

仓库仅保留通用方法、工作流和脱敏后的报告结构，不包含客户原始材料、项目名称、尽调结论、密码、联系方式或本地文件路径。使用时仍应将原始资料保持只读，并按项目授权范围处理。

本工具用于辅助投资机构法律尽调，不替代执业律师根据完整事实出具的正式法律意见。
