# 专项：知识产权及争议

## 核心目标

建立“产品/技术—权利—人员—来源—使用主体”映射，判断核心技术是否归目标集团所有、能否持续使用、是否侵犯第三方权利以及是否受高校、研究院或前雇主约束。

## 最低资料依赖

- 产品与技术架构、核心技术清单、研发路线和权利清单；
- 专利、商标、软著、域名、集成电路布图设计、商业秘密及申请/续展文件；
- 发明人/作者名单、入离职时间、岗位职责、研发记录、代码和设计版本记录；
- 职务成果、保密、知识产权归属、竞业、转让、许可、合作开发、委托开发协议；
- 高校/研究院课题、经费、实验室、设备、学生参与及成果转化材料；
- 前雇主成果、公开代码、开源软件、第三方数据/模型/字体/素材及许可证清单；
- 异议、无效、侵权警告、诉讼仲裁、行政调查及和解材料。

## 分析步骤

1. 从产品功能和收入来源反推不可替代的技术与品牌；
2. 对每项核心成果识别完成时间、完成人、资源来源和首次固定载体；
3. 核验登记权利人与实际研发、使用及收款主体是否一致；
4. 审查转让/许可范围、期限、地域、排他性、分许可、控制权变化和终止后果；
5. 审查开源组件及第三方内容是否产生披露源码、署名、再许可或商业使用限制；
6. 对争议建立时间线，评估禁令、赔偿、无效、替代成本及对客户合同的传导；
7. 将确权、转让、授权、隔离、重构、保险和专项赔偿转化为交易动作。

## 输出要求

用矩阵列示核心产品、关键技术、权利类型、权利人、完成人、来源、证据、使用主体、限制和争议。缺少登记不等于当然无权利，已有证书也不当然证明无权属争议。
