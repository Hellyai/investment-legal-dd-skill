# 完整报告成文格式

## 选择原则

正式完整版可以选择以下任一种格式。格式只决定叙事顺序，不改变调查范围、事实颗粒度、法律论证、证据追溯和附表要求。参考报告只用于提炼结构和表达方式，不复制项目事实、客户信息或大段原文。

未指定时，根据项目复杂度和投资人用途选择，并在交付摘要中说明；无法判断且选择会实质影响阅读方式时再询问用户。

## 格式A：综合展开型

采用成熟律所综合展开型报告的结构特点：先完整说明委托范围、集团和业务，再按法律模块系统展开；各章节充分记录事实、文件、规则和分析，重大问题在前部汇总，在正文对应章节详细论证。

适合：主体较多、业务成熟、合同量大、需要接近传统律所成文报告或供后续融资持续使用的项目。

建议顺序：基础说明—集团与业务—主要法律问题—主体与沿革—融资股权—治理团队—业务合同—资质—知识产权—资产负债—劳动税务—行业合规—争议境外—限定与附件。

## 格式B：问题前置型

采用投资决策问题前置型报告的结构特点：基础说明后立即呈现主要法律问题，再按主体、时间线和法律模块完整展开事实和论证；每项主要问题与正文、证据和交易动作相互索引。

适合：投资决策时点紧、重大风险突出、交易条件需要与尽调问题紧密联动，同时仍要求保留正式完整版事实底稿的项目。

建议顺序：基础说明—主要法律问题—集团与业务—主体逐项沿革—融资股权—其余法律模块—未决事项—交易闭环—附件。

## 禁止的压缩

无论选择哪种格式，均不得：

- 用主要问题表替代正文事实和法律分析；
- 将多个集团主体合并为一段概括；
- 将历轮融资仅汇总为当前股权结构；
- 以“详见资料”替代重大合同、知识产权或资质明细；
- 只给交易建议而不说明事实、证据、适用规则和投资影响。
