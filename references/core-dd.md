# 通用尽调底盘

专项和行业包用于调整深度，不替代以下基础范围：

1. 主体资格、集团架构、分支机构及实际经营主体；
2. 设立、历次股权变动、融资、股东出资及代持；
3. 公司治理、授权、控制权安排和股东特殊权利；
4. 核心团队、劳动用工、社保公积金和激励计划；
5. 主营业务、收入模式、业务真实性及重大合同；
6. 业务资质、行业准入、产品认证及持续合规；
7. 知识产权、数据、技术来源及争议；
8. 土地房产、租赁、设备和其他重要资产；
9. 融资、担保、负债、对外承诺及或有负债；
10. 关联方、关联交易、资金占用及同业竞争；
11. 税务、财政补贴、政府协议和产业落地义务；
12. 诉讼仲裁、行政处罚、调查、失信和重大舆情；
13. 安全生产、环保、消防、网络安全和个人信息保护；
14. 境外主体、跨境资金、出口管制、制裁和境外经营；
15. 本轮交易所需批准、第三方同意、交割条件和投后整改。

## 范围调整

- 早期项目以团队、技术来源、股权权属、行业准入和未来可融资性为重，不因没有合同而简单标记“无风险”。
- 成熟项目增加业务真实性、客户供应商集中、关联交易、回款履约、控制权限制和历史合规抽样。
- 集团经营时按实际主体核验资产、人员、许可、合同和收入，不仅核验融资主体。
- 用户要求主题定向输出时，正文可聚焦主题，但仍披露对投资结论有实质影响的范围外红旗及明确的未核范围。
